# Selected public results

This directory contains lightweight, final scientific evidence intended for repository visitors. It is not the project's runtime output directory.

- `summary/` — frozen product and validation-design manifests plus compact headline metrics;
- `tables/` — final deployment ablation and before/after safeguard effects;
- `selected_outputs/` — the frozen blank-label 400-parcel validation sample.
- [`eofm_benchmark_v1/`](eofm_benchmark_v1/README.md) — four-representation transfer, few-shot and OOD aggregate evidence with artifact hashes.

The two small label-free field-delineation AOIs are public reproducibility examples under [`data/examples/`](../data/examples/).

Generated rasters, GeoPackages, checkpoints, logs, per-tile products, and intermediate experiment trees remain local under the ignored `outputs/` convention. Code continues to use those runtime paths. See [`DATA_AVAILABILITY.md`](../DATA_AVAILABILITY.md) for reconstruction and data-placement instructions.
